## Цель

2. Собрать полный inventory: `экран/состояние → кнопка или интерактивный элемент → предусловие (auth, selected game, safety, data loaded) → следующий экран/модал/фон → действие над данными → Back/close/return`. Учитывать loading/empty/error, deep link, active game vs finished game и аккаунт, особенно **Главная → последняя партия → Review**, Library → review/Stockfish, Analysis → выбор партии, Queue/Background → исходный экран, Training → повтор задачи, Progress → детализация.

4. Дать **короткие предложения оптимизации** с числом кликов *до/после* и impact/risks, не создавать код/вторую реализацию/новые routes и не отправлять исправления Codex до утверждения владельцем. Показать спорные продуктовые варианты на согласование.
