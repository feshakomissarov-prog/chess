## 1. P0 — Home: производительность строго ≤1000 мс на настоящих данных

**ПРИОРИТЕТ 0. Один воспроизведённый запуск >1000 мс = **FAIL**. Count без точности, источника, рейтинга и трёх корректных последних игр **не засчитывается**. Нельзя заменить ни средним, ни P95, ни отдельным JSON benchmark.
