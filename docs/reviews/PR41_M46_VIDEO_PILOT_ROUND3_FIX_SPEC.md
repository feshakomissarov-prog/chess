## P1-V3-05 — График Δ: устранить выход линий за границы + сделать понятную шкалу

**Видео ~03:10–06:50:** график «Изменение за ход» показывает ломаную с экстремальными пиками, линии выходят за верхнюю/нижнюю границу. Ось подписана \`+2,0 ... −2,0\` вне зависимости от фактического Δ.

**Подтверждённый root cause:** \`ReviewGraph._values()\` в \`delta_mode\` возвращает неограниченные centipawn differences, а \`ReviewGraph.paintEvent()\` проецирует любое Δ на **фиксированную** шкалу ±200 cp и **не clip-ит** линии. В обычном графике scores clamp-ятся до ±200, хотя tooltip сообщает настоящие числа. Mate ассоциируется с edge marker; \`evaluation_label(..., mate_white=0)\` также выдаёт бессмысленное «мат через 0» — проверить и отобразить terminal state корректно.

- В Δ режиме лучше **столбики** вверх/вниз от 0 по полуходам; dynamic symmetric axis (например max absolute 95th percentile + explicit outliers) **или** ограниченная шкала с честным видимым \`>\` на выбросах; ни одной точки/линии за рамкой \`plotRect\`, использовать painter clip и тесты значений ±0.2, ±2, ±15, mate/unknown.
- Подписи осей \`Δ оценки за белых\` и реальные деления, \`0\` различимая линия, отрицательное движение не есть автоматически плохой ход чёрных. Tooltip: move, before, after, Δwhite и Δmover, источник/run, mate отдельно.
- Обычный график (оценка позиции) также честно показывает насыщение за пределом шкалы либо выбирает осмысленный диапазон, не изображая +12.0 визуально как ровно +2.0 без маркера/легенды.
- Сегменты с пропущенными score не соединять. Реальные фазы (если есть) показывать; no missing = no invented. Флажок типов маркеров off by default, **обычные точки** можно оставить, но легенда не должна заявлять показ неактивных маркеров.
- Кликом по графику выбирается соответствующий saved ply, synchronized board/SAN/eval. Если режим delta — только positions with **valid comparable pair**. Qt render regression screenshot and pixel/coordinate asserts on plotRect.
