# «Играть» · краткая карточка решений владельца

**Дата:** 07.11.2026. **Статус:** концепция согласована; **два эталонных арта одобрены владельцем** (AI и «Друг по ссылке»); подробное ТЗ записано. **Не передано Codex.**

**Визуальные эталоны (локально у владельца):** папка `C:\Users\Михаил\Desktop\Пример\`:
- `Изображение ChatGPT 7 нояб. 2026 г., 19_38_56-1` — **Lichess AI**, выбор режима и параметры до запуска.
- `Изображение ChatGPT 7 нояб. 2026 г., 19_38_58-2` — **Друг по ссылке**, приглашение уже создано, показаны копирование и отмена.

Расширения уточнять по локальным файлам. **Не считать эти картинки фактической сборкой** и не переносить демонстрационные ник/URL/часы/число игр как реальные данные. При реализации Codex должен открыть оба оригинала и сравнить Windows screenshots. Остальные два режима/пустые и ошибочные состояния определяются текстом ТЗ.

## Что меняем

**Было:** огромное поле «Режим» со списком, сверху много пустоты и длинная общая форма; одновременно есть карточки тех же режимов — дублирующие элементы.

**Будет:** ровно **4 большие карточки выбора новой игры в сетке 2×2**: **Lichess AI**, **Друг по ссылке**, **Вызвать игрока по имени Lichess**, **Свободная доска**. По клику карточки меняется **ОДНА общая панель параметров под ними**. Сама карточка НЕ запускает игру.

**Отдельно над карточками:** когда есть активные сетевые партии — компактное «Продолжить партию» или «Все активные N». Это не пятая карточка новой игры.

| Карточка | Поля нижней панели | Основная кнопка |
| --- | --- | --- |
| **Lichess AI** | Цвет; время (пресеты/свой); уровень 1–8 | Играть против Lichess AI |
| **Друг по ссылке** | Цвет; время; обычная/рейтинговая* | Создать приглашение → подтверждённая ссылка → Копировать / Отменить |
| **Вызвать игрока** | Ник Lichess; цвет; время; обычная/рейтинговая* | Отправить вызов → Ожидаем ответ / Отменить |
| **Свободная доска** | Нет лишних сетевых параметров; игра за обе стороны | Открыть свободную доску |

*Только в рамках реальных возможностей Lichess endpoint. «Без часов» нельзя путать с correspondence/другим видом партии без подтверждения API.

**Сохранение:** каждая карточка помнит свой цвет, контроль времени, кастомные минуты/инкремент, AI-уровень, рейтинговость и при необходимости ник; режим восстанавливается при следующем открытии. Перенести существующие сохранённые AI defaults. **Повторное открытие НЕ запускает игру.**

**При ожидании:** повторные POST запрещены; приглашение реально подтверждается сервером; запрос отмены не равен подтверждённой отмене. Не терять active game/подключение, Fair Play и original board.

**Палитра:** текущая тёмно-синяя/фиолетовая Chess Coach без изменения. Меняется только раскладка и смысл элементов. **Новое приложение не создаём.**

## Что нельзя потерять

Доступ к активным играм, синхронизацию Lichess, friend URL+copy+cancel, nickname challenge+cancel, все уровни AI 1–8, цвет, время+свои параметры, рейтинг там где разрешён, сохранение прошлых параметров, локальную доску, возврат к текущей партии, offline/error/429 statuses.

## Чего пока не будет

**Не включаем в эту страницу:** случайный подбор игрока Lichess, локальный Stockfish как отдельный соперник, FEN/PGN редактор и анализ, репертуар/AI-тренера. Игровую доску со всеми командами разбираем отдельно, чтобы сделать цельную будущую UX-архитектуру.
