# Игровое окно + Разбор · краткая карточка UX для владельца

**07.11.2026 · Статус: ПРЕДЛОЖЕНИЕ, пока НЕ УТВЕРЖДЕНО.** Это не финальное ТЗ Codex и не разрешение писать код. Параллельный §15 PR #45 остаётся самостоятельной работой.

## Главное предложение

**Один GAME workspace** (активная игра → фокус → завершённая партия без автоматического перехода) и **один REVIEW workspace** для законченной игры/PGN. Не делать отдельных экранов под каждую кнопку или событие.

| Состояние | Что увидит игрок | Что уходит с первого плана |
| --- | --- | --- |
| **Идёт партия** | **Большая доска**, имена и реальные часы, ходы, видимые «Сдаться / Ничья / Возврат» | большая строка «Размер доски», кнопка «Завершённые партии», пустой «Предход», дубли статусов |
| **Фокус** | Доска **действительно растёт**, часы/имена сохраняются, выход из фокуса и компактная «Управление» доступны | правый список ходов и вторичная навигация, возможно sidebar временно свёрнут |
| **Партия завершилась** | **Та же доска** и последняя позиция, замороженные часы, история, ровно **«Разобрать / Вызвать снова»** | активные онлайн-команды; никаких ResultPage, popup и авто Stockfish |
| **Свободная доска** | доска за обе стороны, история, отмена хода, flip, пометки; локальная оценка по отдельному запросу | surrender/draw/takeback и другие сетевые команды |
| **Review без аналитики** | крупная доска, история, честное «Нет оценок» и **«Проанализировать Stockfish»** | постоянная огромная пустая колонка метрик, график без данных, primary «Мои ошибки · 0» |
| **Review с аналитикой** | доска+ходы, сводка точности/ошибок+источник, интерактивный график, тренировка при подтверждённых ошибках | постоянные технические тексты, избыточная третья колонка; график можно свернуть |

**Палитра, деревянные цвета доски и фигуры не меняются.** Переставляем старые компоненты и меняем видимость в зависимости от состояния, не пишем новую шахматную программу.

## Важные оговорки

1. **Игровые команды нельзя «оптимизировать» удалением.** При человеческой игре «Сдаться», ничья и возврат хода должны оставаться видимыми. В фокусе допускается компактная однокликовая «Управление», но не потеря доступа.
2. **Режим фокуса сейчас технически не перераспределяет размер**: source ограничивает доску сохранённым целевым размером и занятой высотой. Требуется фактический перерасчёт, native Qt screenshot + измерение. Не считать косметическое исчезновение панели полноценным фокусом.
3. **Данные отсутствуют ≠ равны нулю.** Не выводить пустые диаграммы/маркеры, не обещать упражнение при 0 доказанных ошибках. Официальную Lichess и локальную accuracy разделять.
4. **Fair Play остаётся главным:** во время человеческой сетевой партии и при неизвестном статусе ни score, ни PGN-import trick, ни скрытый tooltip не открывают движок.
5. **Уже реализованное не переписывать:** на свежем PR44 завершение уже остаётся на game_page; менять layout, не создавать второй ResultPage.

## Пять дизайнерских решений для обсуждения

- **1. Без часов:** одна аккуратная метка «∞ Без контроля времени» вместо двух крупных дублирующих строк.
- **2. Фокус:** доска максимально большая, правый блок скрывается, sidebar временно можно свернуть; отдельная маленькая кнопка «Управление».
- **3. Разбор:** две базовые зоны (доска + история); статистика раскрывается только когда есть данные и safety.
- **4. График:** в Review при наличии данных, опциональные маркеры ошибок и режим Δ остаются; пустой график не занимает полэкрана.
- **5. Навигация:** из разбора «К игре / К партиям / К анализу» — в зависимости от исходного пути; сохранение выбранного хода и позиции списка.
