# Chess Coach — раздел «Анализ»: дизайн-варианты на согласование

**Дата:** 04.11.2026. **СТАТУС: ОТКРЫТАЯ ДИСКУССИЯ. НИ ОДИН ИЗ ВАРИАНТОВ НЕ УТВЕРЖДЁН.** Согласованные части общепрограммного UX находятся в [UX-B1](UX_APPROVED_BASELINE_V1.md), которую нельзя подменять этим документом. Реализации/PR Codex пока нет.

## Поставленный владельцем вопрос

В отличие от мобильного приложения, Chess Coach является Windows desktop инструментом. Владельцу не нужен сценарий «отсканировать фотографию доски ИИ». Сложность раздела «Анализ»: чьи партии разбираем, как перенести внешнюю партию/позицию и не получить дублирование «Моих партий» и «Анализа». При этом «Массовый анализ с прогрессом/параметрами» и большой будущий «Исследование дебютов» уже **концептуально согласованы**.

## Фундаментальное различие источников

- **Архивная партия:** уже сохранена у пользователя в «Моих партиях», может быть Lichess (своей или другой из корректно импортированного PGN), локально сыграна или вручную импортирована. У неё есть идентичность и может существовать сохранённый анализ L/S.
- **Внешний PGN:** файлы \`.pgn\` с целой партией/ходами (возможно с начальным FEN), например скачанные с турнира/сайта или присланные другом. На desktop можно использовать стандартный диалог **«Открыть PGN-файл»** или вставить PGN текстом. **«Открыть для просмотра» ≠ «Сохранить в Мои партии»**; импорт в архив отдельно по инициативе пользователя, с provenance и проверкой дубликатов. Несохранённая временная партия не загрязняет личную аналитику.
- **Отдельная позиция:** FEN — компактная **текстовая** запись одной шахматной позиции (размещение фигур, чей ход, рокировки, взятие на проходе и т.п.). Её можно вставить из браузера, шахматной программы или чужого разбора через Ctrl+V. **Это НЕ фото/OCR**.
- **Ручная расстановка:** редактор доски с перетаскиванием фигур и указанием стороны хода/прав рокировки/en-passant; валидировать корректность, прежде чем использовать Stockfish. На desktop это возможно с мышью даже без файла или FEN.
- **Исследование из текущего просмотра:** «Анализировать позицию с хода 21...» — открыть копию конкретной позиции в локальной исследовательской доске, **не изменяя историю сохранённой партии**. При human live игре запрещено создавать unsafe engine session или раскрывать аналитику через этот способ.

Терминология в UI: **Открыть PGN** (получить извне), **Сохранить партию в архив** (persist), **Экспорт PGN** (вывести из программы), **Вставить FEN** (загрузить одну позицию). Не путать «экспорт» и «импорт».

## Вариант A — 4 крупные карточки в Анализе

\`\`\`text
┌───────────────────────── АНАЛИЗ ────────────────────────────────┐
│ [Разбор партии / PGN]       [Анализ отдельной позиции]          │
│ [Массовый анализ]          [Исследование дебютов (будущее)]     │
└────────────────────────────────────────────────────────────────┘
\`\`\`

**Плюсы:** все четыре сценария сразу видны, быстрый доступ к FEN/editor при частом использовании. **Минусы:** перегружает раздел отдельным инструментом, с которым владелец пока не связывает частую задачу; пользователь думает, будто разбор партии и просмотр её позиции — два полностью разных движка/рабочих пространства. Это может привести к дублям досок, сохранённых оценок и UI.

## Вариант B — рекомендуемый: 3 рабочих направления, редактор внутри общего разбора

\`\`\`text
┌────────────────────────── АНАЛИЗ ───────────────────────────────┐
│                                                                  │
│  ┌─────────────────┐ ┌─────────────────┐ ┌───────────────────┐   │
│  │ Разбор партии   │ │ Массовый анализ │ │ Исследование      │   │
│  │ / PGN           │ │ и очередь       │ │ дебютов           │   │
│  └─────────────────┘ └─────────────────┘ └───────────────────┘   │
│                                                                  │
│  Недавние анализы · Идёт вычисление · [Продолжить]              │
└──────────────────────────────────────────────────────────────────┘
\`\`\`

Вход «Разбор партии/PGN» даёт понятный выбор источника, а не второй архив:

\`\`\`text
┌────────────────────── ОТКРЫТЬ ДЛЯ РАЗБОРА ──────────────────────┐
│   [Выбрать из Моих партий]                                      │
│   [Открыть файл PGN]    [Вставить PGN из буфера]                │
│                                                                  │
│   Дополнительные инструменты: [Пустая доска / редактор]        │
│                                [Вставить FEN]                  │
└──────────────────────────────────────────────────────────────────┘
\`\`\`

Открывается **единый** шахматный workspace с одной доской:
- режим **Партия**: последовательность ходов, навигация, график и ошибки только при наличии сохранённых разрешённых оценок;
- режим **Позиция / Редактор** (вторичная вкладка/кнопка в панели инструментов этой же доски): FEN/расстановка фигур/проверка корректности и по запросу Stockfish в разрешённом офлайн/завершённом контексте;
- общий режим **Исследовать вариант от выбранного хода** без порчи исходного PGN или игрового состояния. Разрешение на analysis — *всегда* свежее и fail-closed. При открытии файла/позиции **Stockfish НЕ запускается автоматически**.

### Пример workspace, после выбора партии

\`\`\`text
┌────────────── РАЗБОР / ПАРТИЯ  ─────────────────────────────────┐
│ [← Анализ] [Из моих партий] [Открыть PGN] [Вставить FEN / ⚙]   │
├────────────────────────────────┬──────────────────────────────┤
│                                │ Ходы / Ошибки / Варианты       │
│          ДОСКА                 │ [Информация о партии]         │
│                                │ [Настройки Stockfish]        │
│  [◀] [▶] [К началу] [К концу]  │ [Запустить анализ]*            │
├────────────────────────────────┴──────────────────────────────┤
│ ГРАФИК ОЦЕНКИ (если источник/разрешение есть)                   │
└───────────────────────────────────────────────────────────────┘
* После актуального Fair Play preflight, не на живой human игре.
\`\`\`

**Плюсы B:** 3 больших понятных направления вместо 4; один view + board; проще сохранить единое место для всех оценок; desktop-import PGN/FEN виден там, где нужен; не перегружаем Главную. **Минусы:** чаще используемый пользователем редактор позиции окажется на один дополнительный клик глубже — можно впоследствии вынести отдельную кнопку при подтверждённом частом использовании, без переделки общей доски.

## Что именно «Разбор партии» должен уметь (предложение, не утверждено)

1. **Своя завершённая партия**: пользователь выбирает из того же каталога «Мои партии» с фильтрами; клик в карточке → «Разобрать» открывает этот же workspace на конкретном \`game_id\`. Нет ещё одной отдельной сущности игры.
2. **Чужая/внешняя партия:** открыть стандартный \`.pgn\` с диска или вставить PGN; показывать «Временная партия · не сохранена», источник и автора/игроков из PGN; кнопка «Сохранить в Мои партии» отдельно и с подтверждением типа/источника. Если PGN contains multiple games — показать выбор игры/игр (не анализировать все автоматически).
3. **Позиция без партии:** вторичная команда «Вставить FEN» или «Расставить фигуры» открывает board editor. Отдельные значения FEN: чей ход, доступные рокировки и en passant (проверка). Может создать **временную позицию**, не поддельную историческую партию и не статистику личных ошибок.
4. **Эксперимент с ходом из PGN:** скопировать позицию на 21-м ходе в локальную доску «Исследовать вариант», сохранив исходный PGN и его доказательства. Кнопка «Вернуться к оригиналу».
5. **Открыть без оценки ≠ запустить Stockfish.** Опции «Посмотреть», «Запустить анализ», «Сохранить» должны иметь разные намерения/статусы.
6. **Активная Lichess human игра:** никаких импортов позиции через текущую живую партию в движковую доску, подсказок/PV/скрытых классификаций. Даже импорт внешнего PGN/отдельной позиции не должен ослабить общую safety policy.

## «Массовый анализ» и «Исследование дебютов» — принятие на уровне направлений

**Массовый анализ:** единственный control plane для выбора партий, \`nodes\`/depth, queued/running/paused/completed, progress, sources/cache/resume/history, fairness; «Мои партии» только показывает краткий status и deep-link сюда. Два независимых batch scheduler запрещены.

**Исследование дебютов:** целевой *крупный* аналитический модуль с деревом ходов, ECO, транспозициями, частотой собственных продолжений, главными позициями и вариантами, типовыми планами, verified Stockfish optional. **Не путать** с разделом «Обучение → Мой репертуар»: там пользователь выбирает, что играть, запоминает и тренирует линии. Подробный wireframe большой вкладки дебютов ещё не утверждён, реализовывать сейчас нельзя.

## Главная открытая развилка

**A:** четыре отдельных входа, среди них заметный самостоятельный «Анализ позиции».

**B (рекомендую):** три главных входа — «Разбор партии / PGN», «Массовый анализ», «Исследование дебютов». FEN и ручной редактор — инструменты внутри общего разбора/доски, без отдельной большой карточки на landing.

После утверждения варианта определить поля «Разбор партии» и подробный layout дебютного инструмента. **Сейчас ни один вариант не объявлять утверждённым.**
