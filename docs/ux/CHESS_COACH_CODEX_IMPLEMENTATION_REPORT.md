## Реализовано

- Пять основных маршрутов оболочки; «Мои партии» вложено в Analysis, Settings остаётся отдельным пунктом, «Фон» доступен из шапки.
- Analysis landing содержит четыре карточки 2×2, две FUTURE-карточки disabled; разбор открывает три вкладки: «Мои партии», «Вставить ходы», «Расставить позицию».
- Play показывает режимные карточки с иконками и отметкой выбора, контекстную форму выбранного режима и сохраняет настройки режимов отдельно; сетка формы перестраивается по количеству полей, выбор режима не создаёт игру автоматически. В офлайн-режиме сетевые действия недоступны, локальная доска остаётся доступна.
- Сохранены board/game handlers, Focus и экран окончания партии на той же доске. На широких окнах навигация остаётся раскрытой во время игры согласно UX-04.
- Импорт поддерживает несколько партий из PGN с выбором партии; временный импорт не записывается как пользовательская партия. Исправлено сопоставление одинаковых PGN по линии ходов.
- Вложенный редактор позиции перестроен в двухколоночный вид с фигурной палитрой, параметрами хода/рокировок/en passant и действиями с FEN; проверен при 1280×720.
- Review без реальных оценок больше не показывает пустые метрики, ложную шкалу графика или advantage bar. При наличии безопасных сохранённых оценок остаются источники, график, тренировка ошибок и действия Stockfish. Неизвестный цвет владельца не переименовывается в «Я/Соперник».
- Сохранены существующие PuzzleHistoryPage, Statistics/Progress, Settings, Background Operations, SQLite/PGN и Fair Play admission paths.
