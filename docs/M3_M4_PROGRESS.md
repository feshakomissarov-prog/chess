# M3–M4 реализация: журнал блоков

Этот файл фиксирует кодовые блоки и фактические локальные проверки. Он не является разрешением на сетевой импорт, OAuth-тест или анализ реальных партий.

## Блок 1 — база и библиотека (ветка `codex/m3-db-library`)

- `games` сохранена; SQLite `user_version=1`, миграция добавляет поля источника, линии и ошибки импорта.
- Перед миграцией существующей БД создаётся непрезаписываемая копия через SQLite backup API.
- Добавлены ревизии линий, нормализованные SAN/UCI ходы и позиции, включая позицию `ply=0`, а также текстовые заметки.
- Ветка линии после takeback получает новую ревизию; старые ходы/позиции/заметки сохраняются.
- Библиотека поддерживает поиск, постраничную выборку, просмотр, экспорт PGN и заметку к начальной позиции.
- Проверки локально: `python -m pytest -o addopts= -q` — 114 passed; `python -m compileall -q src tests` — PASS; `git diff --check` — PASS.
- Это Python 3.11.5 в доступной Windows-среде. CI Python 3.12 для этого нового блока ещё не запускался.
- Не проверялись реальный архив Lichess, реальный Stockfish и ручной интерактивный просмотр окна.

## Запланированные блоки

1. Полный и инкрементальный экспорт Lichess с аккаунтными checkpoint, остановкой/возобновлением и мок-тестами NDJSON.
2. Хранилище анализов и безопасный анализ только завершённых партий локальным Stockfish; без скачивания движка.
3. Общая статистика с прозрачным покрытием оценок и знаменателями.
4. Импорт и статистика личной истории задач Lichess; новый OAuth scope и сеть останутся неактивными до явного действия владельца.

Переходы между планами подтверждаются в отдельных reviewable PR; merge не выполняется автоматически.
