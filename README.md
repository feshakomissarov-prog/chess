# Chess Coach — персональный шахматный ИИ-тренер

**Статус на 31.10.2026:** PR #2 (M0) и PR #3 (Lichess) слиты в `main`. Текущий этап — отдельные проверяемые PR по [эпику #6](https://github.com/feshakomissarov-prog/chess/issues/6): начальная ветка P0 исправляет жизненный цикл ручных пометок, добавляет явный безопасный офлайн-запуск и Windows CI. Отчёт по текущей ветке и проверкам — [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md). Архивный импорт, Stockfish-анализ и голос пока не реализованы.

## Идея

Chess Coach — планируемое настольное приложение для улучшения игры в шахматы на основе собственных партий, размышлений игрока и персональных тренировок.

Цель — не просто показать лучший ход Stockfish, а помочь понять, **что игрок видел в позиции, какие варианты рассматривал, чего не заметил и как отработать конкретную ошибку**. Особое внимание — умению замечать угрозы и предугадывать разумные ответы соперника: почему один ход оказывается естественным или почти вынужденным, хотя на первый взгляд вариантов много.

Проект в первую очередь задуман как **индивидуальный тренер**, а не как очередной интерфейс шахматного движка.

## Как это должно работать

1. **Игра.** Уже работает прототип: пользователь запускает Chess Coach, подключает аккаунт Lichess, создаёт нерейтинговую партию по ссылке или с AI и играет внутри приложения. Остальные сценарии и устойчивость сети продолжаем проверять.
2. **Фиксация мыслей.** Во время партии приложение записывает только микрофон пользователя. Аудиокомментарии автоматически привязываются к позициям и ходам; запись начинается после первого хода белых и разделяется при последующих изменениях позиции. Во время онлайн-игры против человека нет подсказок движка или ИИ.
3. **Локальная история.** Ходы, результаты, доступные данные о времени и комментарии сохраняются на компьютере. После партии аудио в фоне превращается в текст; исходные записи можно архивировать или удалять после успешной обработки. Следующую партию можно начать, не дожидаясь анализа.
4. **Разбор.** Пользователь открывает историю партий и выбирает позиции для обсуждения. Система также предлагает критические моменты, найденные Stockfish. Сначала игрок восстанавливает и проверяет свои рассуждения, затем сравнивает их с вариантами движка и обсуждает выводы с ИИ-тренером.
5. **Тренировки.** Тренер ищет повторяющиеся, подтверждённые партиями проблемы и предлагает небольшие цели на будущие игры: например, внимательнее проверять ответы соперника, изучить определённую пешечную структуру или потренировать дебют. По новым партиям проверяется прогресс.

В перспективе рассматриваются дебютная библиотека, упражнения из собственных ошибок и импорт чужих партий. Детали интерфейса и состав первого прототипа ещё обсуждаются.

## Технологии и организация работы

Проект разрабатывается **совместно с OpenAI Codex** (программирование и тестирование) и **ChatGPT** (обсуждение концепции, требований и проектных решений). В самом приложении предполагается **ИИ-тренер на основе языковой модели**: она будет вести обучающий диалог, опираясь на проверяемые шахматные данные. Это разные роли, а не обещание постоянного присутствия ChatGPT в приложении.

Предполагаемые компоненты: Lichess API для партий, Stockfish для анализа, распознавание речи для голосовых заметок и локальная база для истории и наблюдений. Для первого прототипа планируются Windows, Python, PySide6 и python-chess. **Основа интерфейса шахматной доски выбрана: [chess-widgets](https://github.com/leszekhanusz/chess-widgets) (MIT для кода)**; предходы, ручные стрелки и недостающие элементы будут адаптированы в M0. Лицензии SVG-фигур и python-chess проверяются отдельно. Остальные решения уточняются по мере разработки.

## Принципы

- **Сначала думать самому.** В режиме разбора лучший ход не обязательно раскрывается до самостоятельного ответа игрока.
- **Никаких подсказок в онлайн-партии против человека.** Во время такой игры разрешена только пассивная фиксация собственных размышлений.
- **Ошибки — не диагнозы.** Выводы о слабых местах являются проверяемыми гипотезами, а не попыткой «прочитать мысли».
- **Локальные данные.** Приоритет — хранению партий, расшифровок и результатов анализа на компьютере; подключение облачной модели будет отдельным решением.
- **Практическая польза.** Разбор должен приводить к конкретным упражнениям и измеримым маленьким улучшениям.
- **Русский язык** — основной язык интерфейса и обсуждений на первом этапе.

Сначала расширяем **уже существующую** локальную SQLite и импортируем завершённые партии Lichess с возможностью возобновления; при повторной синхронизации загружаем только новые и изменившиеся игры, не весь архив. Затем отображаем доступную точность Lichess и график анализа завершённых партий (локальный Stockfish, если оценок нет). После этого добавляем микрофон пользователя, сегментацию голосовых мыслей по каждой смене позиции и привязку ручных стрелок/кругов ко времени, позиции и отдельным планам.

## Запуск на Windows

Из корня репозитория и при существующем `.venv` обычный запуск выглядит так:

```powershell
cd G:\project\chess
git status --short
git switch main
git pull --ff-only
.\.venv\Scripts\python.exe -m chess_coach
```

Для безопасного офлайн-smoke запуска без чтения OAuth-данных и без сетевых вызовов используйте `--offline`:

```powershell
.\.venv\Scripts\python.exe -m chess_coach --offline
```

Для чистой установки требуется Python **3.12+** по `pyproject.toml`. Результаты проверок конкретной ветки и установленная у исполнителя версия указаны в [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md).


## Ярлык Windows

Для ежедневного запуска предусмотрен ярлык Windows (однажды созданный ярлык работает двойным щелчком). При желании создать его из PowerShell, **если системная execution policy разрешает запуск скриптов**:

```powershell
.\scripts\create_desktop_shortcut.ps1
```

Если запуск скрипта запрещён политикой Windows, не обходите её ради установки ярлыка; используйте уже созданный ярлык или обычный запуск из терминала. Скрипт использует системный путь Desktop (в том числе OneDrive), проверяет наличие `.venv\Scripts\pythonw.exe`, предупреждает о версии Python ниже 3.12 и не перезаписывает существующий ярлык. Он не устанавливает пакеты и не меняет системные настройки. Запуск ярлыка использует `pythonw.exe -m chess_coach` с рабочей папкой репозитория. Ошибки запуска записываются в `%LOCALAPPDATA%\ChessCoach\logs\crash.log` без текста исключения/партии/OAuth.

Текущая задача и фактические результаты проверок описаны в [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md). Qt-тесты запускаются с `QT_QPA_PLATFORM=offscreen` и отдельными временными данными. Внимание: при обычном старте с ранее сохранённым OAuth приложение может подключиться к Lichess и восстановить активную игровую сессию. Перед тестами убедитесь, что это ожидаемо. Реальные сетевые проверки Lichess выполняйте только с отдельного разрешения владельца.
