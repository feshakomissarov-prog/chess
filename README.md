# Chess Coach — M0

Локальная интерактивная шахматная доска для Windows. M0 включает офлайн-партию, SAN-журнал, просмотр истории, ручные пометки, тестируемый предход и настройки. Подключения к Lichess, Stockfish, GPT и интернет-запросов в приложении нет.

## Запуск в Windows

Требуются Windows 10/11 x64 и Python 3.12 или новее с `py` launcher.

Откройте PowerShell в папке проекта:

```powershell
cd G:\project\chess
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m chess_coach
```

Если PowerShell блокирует активацию окружения, команды можно запускать без активации через `.\.venv\Scripts\python -m pip ...` и `.\.venv\Scripts\python -m chess_coach`.

Тесты:

```powershell
python -m pytest
```

Зависимости проекта фиксируют основу доски `chess-widgets==0.5.0`; поддерживаемые версии PySide6 и python-chess ограничены в `pyproject.toml`. Для разработки Windows можно использовать Python 3.12+.

## Управление

- Левый клик по своей фигуре, затем по целевой клетке — ход; перетаскивание делает тот же ход.
- При превращении открывается явный выбор ферзя, ладьи, слона или коня. Отмена оставляет позицию прежней.
- Правая протяжка рисует стрелку, правый клик выделяет клетку; повторное действие снимает пометку. «Очистить пометки» удаляет только ручные отметки.
- Кнопки `|<`, `<`, `>`, `>|` и журнал ходов переключают отображаемую историю, не меняя живую партию. Ход доступен после возврата к текущей позиции.
- Для проверки предхода выберите в настройках свою сторону. Сделайте ход своей стороны, пока ходит соперник поставьте предход клик-клик или перетаскиванием, затем выберите легальный ход соперника в блоке «Проверка предходов». Предход повторно проверяется после этого хода; он не входит в журнал до успешного выполнения.
- `Esc` отменяет выставленный предход.

Настройки интерфейса хранятся в `QSettings` Windows для пользователя и сохраняются между запусками. Новая партия очищает текущую локальную позицию после подтверждения; M0 не добавляет партии в библиотеку.

## Ручная проверка на Windows

Перед переходом к M1 проверьте внешний вид и следующие сценарии:

1. Запуск, стартовая позиция, координаты, размеры окна и HiDPI.
2. `e2–e4` двумя кликами и `e7–e5` перетаскиванием; недопустимый ход ничего не меняет.
3. Рокировка и взятие на проходе; продвижение пешки каждым из Q/R/B/N и отмена выбора.
4. Переворот доски и ориентация координат.
5. Правая стрелка/кружок, повторное снятие, очистка без изменения партии.
6. Просмотр старого хода и возврат к актуальной позиции.
7. Успешный предход (например, после `e4` поставить `Ng1–f3`, тестовый ответ `e5`) и отменённый предход после взятия исходной фигуры.
8. Смена настроек, перезапуск приложения, проверка отсутствия оценки позиции и сетевого подключения.
