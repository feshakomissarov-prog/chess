**Chess Coach — настольное приложение для игры в шахматы, разбора собственных партий и постепенного развития шахматных навыков.**

Проект создаётся как **персональный шахматный тренер**: не просто показать, где игрок ошибся, а помочь понять *почему*, найти повторяющиеся проблемы, потренировать нужные навыки и проверить прогресс.

**Платформа:** Windows · **Язык интерфейса:** русский · **Статус:** активная разработка, предварительная версия.

> [!IMPORTANT]
> Chess Coach пока **не является готовым массовым релизом**. Единый рабочий интерфейс и двухуровневое сохранение аналитики включены в `main` после [слияния PR #46](https://github.com/feshakomissarov-prog/chess/pull/46). Windows CI прошёл; **ручное сравнение UX-01…UX-13, проверка реальной пользовательской базы и живых Lichess-сценариев ещё не завершены**. Для установки сейчас используется исходный код; готового официального Windows-установщика в репозитории нет.

## Что умеет Chess Coach

### ♟ Играть
- Локальная шахматная доска и игра через интеграцию с **Lichess**.
- Игра с Lichess AI, приглашение друга, вызов другого игрока.
- История ходов, управление доской, обычные предходы и шахматные звуки.
- Безопасное разделение текущей онлайн-партии и последующего анализа.

### 📚 Хранить и разбирать партии
- Локальный архив партий в **SQLite**, синхронизация с Lichess.
- Импорт и экспорт **PGN**, работа с позициями **FEN**.
- Просмотр партии по ходам, шахматная доска, графики и связанные показатели — там, где имеются подтверждённые аналитические данные.
- Анализ завершённых партий с помощью **Stockfish**: отдельные партии и пакетная обработка.
- Разбор ошибок и тренировочные сценарии на основе сохранённых оценок.

### 📈 Отслеживать обучение
- Статистика по завершённым партиям, точности и ошибкам с указанием источников.
- История задач Lichess, повторы и отображение прогресса.
- Локальное хранение данных: проект не требует отдельного облачного аккаунта Chess Coach.

Возможности развиваются поэтапно. Наличие функции в коде **не означает**, что каждый её сценарий уже прошёл ручную проверку на реальном Lichess и пользовательской базе.

## Как установить на Windows

Сейчас Chess Coach запускается **из исходного кода**, без отдельного установщика.

**Потребуется:**
- Windows 10/11;
- **Python 3.12 или новее**;
- **Git** для скачивания исходников;
- подключение к интернету для установки Python-зависимостей и для функций Lichess.

### 1. Скачать репозиторий

Откройте **PowerShell** и выполните:

```powershell
git clone https://github.com/feshakomissarov-prog/chess.git
cd chess
```

Если Git не установлен, можно выбрать **Code → Download ZIP** на странице репозитория, распаковать архив и открыть PowerShell в полученной папке.

### 2. Создать окружение Python

```powershell
py -3.12 -m venv .venv312
```

Если команда `py` отсутствует, используйте установленный Python 3.12+ через `python -m venv .venv312`.

### 3. Установить зависимости

```powershell
.\.venv312\Scripts\python.exe -m pip install --upgrade pip
.\.venv312\Scripts\python.exe -m pip install -e .
```

Основные зависимости установятся из `pyproject.toml`.

### 4. Запустить Chess Coach

```powershell
.\.venv312\Scripts\python.exe -m chess_coach
```

После установки также можно запускать приложение двойным щелчком по **`launch_chess_coach.cmd`** в корне проекта.

**Полезные режимы запуска:**

```powershell
# Подключение к Lichess только вручную
.\.venv312\Scripts\python.exe -m chess_coach --manual-connect

# Изолированный тестовый режим без OAuth и сети
.\.venv312\Scripts\python.exe -m chess_coach --offline
```

> [!NOTE]
> Для **локального Stockfish-анализа** необходим отдельно установленный движок Stockfish (UCI). Приложение не загружает его автоматически; путь к исполняемому файлу указывается пользователем в настройках. Подключение к Lichess выполняется отдельно.

### Если приложение не запускается

Проверьте версию Python: `py -3.12 --version`, затем попробуйте `debug_chess_coach.cmd`. Технический журнал приложения находится в каталоге данных Chess Coach в Windows (папка `logs`). **Не публикуйте** личные PGN, SQLite-базы, журналы с приватной информацией или токены доступа в открытых issues.

Для запуска тестов разработчика:

```powershell
.\.venv312\Scripts\python.exe -m pip install -e ".[dev]"
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv312\Scripts\python.exe -m pytest -q
```

## Как устроен проект

Chess Coach — **локальное настольное приложение, а не набор микросервисов**. Основной стек:

| Компонент | Технология |
| --- | --- |
| Интерфейс | Python 3.12+, **PySide6 / Qt** |
| Шахматная логика | **python-chess**, **chess-widgets** |
| История и аналитика | **SQLite**, PGN |
| Игра и синхронизация | **Lichess API / OAuth** |
| Анализ позиций | **Stockfish** через UCI, отдельный движок |
| Автоматическая проверка | **pytest**, **pytest-qt**, GitHub Actions на Windows |

Развитие архитектуры ориентировано на **модульный монолит**, разделение интерфейса, игровых правил, хранения данных и фоновой работы. Подробнее — [архитектурный документ](docs/architecture/CHESS_COACH_TARGET_ARCHITECTURE.md).

## Принципы разработки

- **Fair Play:** никакой движковой помощи во время активной онлайн-партии против человека. Исторические завершённые партии служат для обучения после игры.
- **Сохранность данных:** личная история, партии, оценки и заметки должны сохраняться при обновлениях; изменения SQLite проверяются миграциями.
- **Достоверность:** отсутствующие оценки не подменяются выдуманными значениями; источник аналитики и непроверенные сценарии обозначаются явно.
- **Отзывчивость:** тяжёлые вычисления, сеть и массовая аналитика не должны блокировать интерфейс.
- **Проверяемые изменения:** исходники, тесты, Windows CI, независимое ревью и ручная приёмка до объединения крупных PR.
